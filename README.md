# 涌现 · 美术参考库

[打开在线参考库](https://kagamiurayama.github.io/emergence-art-references/)

为 2D Game Jam 项目整理的美术研究画廊，包含 39 个作品／作者、90 张图片。

- 按 7 类画面语言浏览，按媒介与参考用途交叉筛选。
- 支持搜索、大图切换和单个作品链接分享。
- 每个条目附图片来源、借鉴点与制作成本；比赛作品注明具体赛事分项名次。
- 收录游戏、动画、漫画、电影、插画与角色 IP，并包含匿名整理的组员参考。

## 维护

网页由 `index.html`、`styles.css`、`app.js`、`catalog.js` 和 `images/` 组成，无须构建。
`catalog.json` 是可读的数据副本；修改参考条目时须同步更新 `catalog.js`。
GitHub Pages 从 `main` 分支的仓库根目录发布，`.nojekyll` 保持静态文件原样提供。

## 图片与来源

图片版权归原作者与权利方，仅用于美术研究。收录不代表允许将图片作为游戏资产使用。
网页图片只做缩小和压缩；具体出处、组员供图的来源限制与低清说明见条目详情。
